## Future runtime regression scenarios

The following are deliberately unmarked. They are useful for later balancing/playtesting, not a gate for this implementation pass.

### Visible healing lifecycle (blocked in the audited JSON API)

Do not run or mark these until CDDA exposes the lifecycle capability described in
`HEALING_RESEARCH.md` and a safe JSON implementation exists.

- [ ] A naturally healing wound visibly changes stages without changing its total recovery range.
- [ ] A treated wound cancels/replaces the untreated lifecycle without a stale transition.
- [ ] Reinjury cannot be downgraded later by an older healing timer.
- [ ] The avatar receives exactly one final healing message; NPC recovery is silent.
- [ ] Existing v0.1 saved wounds and newly treated states enter/finish recovery safely.

### Production secondary routing

- [ ] Bash to a standard flesh limb can add one appropriate muscle/connective-tissue/bone/crush result at the correct post-armor tier.
- [ ] Bash to torso can add one internal, hemorrhagic, or thoracic result without stacking every family.
- [ ] Cut and stab to standard limbs select only penetrating soft-tissue outcomes.
- [ ] Stab to torso can select penetrating internal trauma or internal hemorrhage.
- [ ] Bullet damage can select limb fracture/soft-tissue trauma or torso ballistic trauma.
- [ ] Electrical limb damage selects nerve trauma only.
- [ ] Compartment syndrome occurs only after very severe heat damage.
- [ ] Fully resisted damage adds no secondary wound.
- [ ] Head, eyes, and mouth receive no generic limb structural outcome.
- [ ] Full bionic replacement limbs receive no flesh structural outcome.
- [ ] A secondary wound persists across save/load.

### Source-specific respiratory routing

- [ ] Inhaled `smoke_lungs` exposure adds the corresponding torso respiratory wound.
- [ ] Mouth-targeted tear gas adds upper-airway irritation, while eye-only tear gas does not.
- [ ] Mouth-targeted poison/badpoison gas adds toxic inhalation trauma; ingested/systemic poison does not.
- [ ] Mouth-targeted fungus exposure adds fungal respiratory trauma; non-mouth fungal infection does not.
- [ ] Acute `dw_respiratory_impairment` expires naturally.

### Repeated injury and acute chest restriction

- [ ] Re-adding the same eligible secondary wound can invoke its native `wound_progression` relationship.
- [ ] Severe thoracic outcomes apply finite `dw_chest_wall_impairment`, which expires naturally.
